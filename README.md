# LUDC_HTML

This repository contains the HTML source code for the **Leading University Debating Club (LUDC)** website.

## 🌐 About the Project

The LUDC website showcases the activities, achievements, and members of the Leading University Debating Club. It serves as a central hub for updates, events, and contact information for aspiring debaters and interested visitors.

## 📁 Features

- Homepage with club introduction
- Member profiles
- Event announcements
- Contact form
- Responsive layout using HTML and basic CSS
